# ТЗ агенту: SEO на год — первые страницы и первые строки

Версия: 2026-08-20  
Владелец: агент Cursor (скиллы `yandex-local`, `content-writer`, `direct-service-voice`)  
Сайт: https://rem-phone.ru/  
Канал №1: **Яндекс**. Google — вторично.  
Города: Хабаровск, Комсомольск-на-Амуре, Владивосток.

Рабочее ТЗ «себе»: за 12 месяцев (авг 2026 → авг 2027) вывести rem-phone.ru на **первые страницы** и по ключевому ядру — на **первые строки** выдачи по нашей тематике в наших городах.

Конкуренты (Pedant, справочники, локальные мастерские) есть в рынке — учитывать при анализе серпа, **не делать KPI «обогнать Pedant»**. KPI = наши позиции и заявки.

---

## 1. Цель года

1. **Первые строки (топ-1…3)** по приоритетному ядру §3 в регионах Хабаровский край + Приморский край (органика Яндекса).
2. **Первая страница (топ-10)** по расширенному кластеру (услуга×город, бренд×услуга, голова «ремонт телефонов» в региональной выдаче).
3. Органика — **основной** источник визитов и заявок (не прямые/тесты).
4. Индекс: ≥ 80% money-URL из sitemap в `searchable_pages_count` Вебмастера.

Общий запрос «ремонт телефонов» **в наших регионах** — в ядре цели (первые страницы → первые строки). Федеральная выдача «вся Россия» — не обязательный KPI года.

## 3. Семантическое ядро

Частоты — Wordstat 20.08.2026 (`seo/reports/wordstat-2026-08-20.md`; Приморье частично + добор 14.08). Refresh раз в 1–2 месяца.

### Первые строки (топ-1…3) — обязательный фокус

| Запрос | Регион | ≈частота | Посадочная |
|--------|--------|----------|------------|
| ремонт телефонов Хабаровск | Хаб. край | ~1080 | `/`, `/khabarovsk/` |
| ремонт телефонов Владивосток | Приморье | ~1029 | `/vladivostok/` |
| ремонт телефонов Комсомольск | Хаб. край | ~391 | `/komsomolsk-na-amure/` |
| ремонт телефонов (региональная выдача) | оба края | ~2700 / ~4300 | `/` + гео-хабы |
| замена экрана (+ город) | оба | экран ~600–990 | city `screen`, `/services/screen.html` |
| замена батареи (+ город) | оба | ~600–830 | city `battery`, `/services/battery.html` |
| не включается / не заряжается | оба | ~480–870 | `not-on`, `charge` + city по сигналу |

На city-URL в H1 — **один** город. Главная связывает три города и общий интент.

### Первая страница (топ-10), затем дожим в топ-3

| Кластер | Посадочные |
|---------|------------|
| После воды | city `water`, `/services/water.html` |
| Бренд × экран / батарея | `/brands/*-screen.html`, `*-battery.html` |
| Корпус, apps | `/services/body.html`, `apps.html` |
| Бренд-хабы | `/brands/*.html` |

### Хвосты

Камера, apps×город, бренд×КнА/Владивосток — только при спросе в Wordstat/Метрике. Не model×city.

## 4. Старт (факт 20.08.2026)

- ~70 визитов / 30 дн., ~7 с поиска, 2 заявки формы.
- В поиске Яндекса **14** страниц при ~56 в sitemap.
- Карточка Бизнес: дубли, 0 отзывов; фото на модерации.
- Money-URL в основном есть → упор на **индекс, карточку, дожим**, не на спам новыми URL.

## 5. Кварталы

### Q1 (мес. 1–3) — попасть в выдачу

**KPI:** searchable ≥ 35–40; органика ≥ 40% визитов; заявки с поиска каждую неделю; карточка: фото, без дублей, ≥5 отзывов; по ядру «ремонт + город» — видимость / движение к топ-20.

| # | Задача | Кто |
|---|--------|-----|
| 1 | Переобход money-URL в Вебмастере | Владелец + список от агента |
| 2 | Sitemap из `seo/pages.json` | Агент |
| 3 | Яндекс Бизнес: оффер, фото, зона 3 города | Владелец |
| 4 | Усилить `/` и 3 хаба + P0 услуги (title, FAQ, перелинковка) | Агент |
| 5 | Wordstat refresh | Агент / владелец |
| 6 | 1 blog/мес. → услуга + город | content-writer → PR |
| 7 | charge/not-on/camera × город — только по спросу | content-writer |

### Q2 (мес. 4–6) — первая страница по ядру

**KPI:** топ-10 по трём «ремонт + город»; топ-10 screen/battery×Хабаровск; «ремонт телефонов» в крае — топ-10; органика ≥ 100 виз/мес; заявки с органики ≥ 8/мес.

| # | Задача |
|---|--------|
| 1 | Сниппеты и FAQ schema под Wordstat |
| 2 | Перелинковка хаб ↔ услуга ↔ бренд ↔ город |
| 3 | Отзывы после ремонта → карточка |
| 4 | Усилить сильные URL, не плодить зеркала |

### Q3 (мес. 7–9) — первые строки

**KPI:** топ-3 по «ремонт + город» (≥2 из 3 городов); топ-3 по ≥2 услугам×Хабаровск; «ремонт телефонов» в крае — топ-5; заявки не только из Хабаровска.

| # | Задача |
|---|--------|
| 1 | Бренды iPhone/Samsung/Xiaomi под частоту |
| 2 | Brand×КнА/Владивосток — только при сигнале |
| 3 | Ежемесячный срез позиций по ядру §3 |
| 4 | Честный UX: форма, мобильный CTA, ясный оффер |

### Q4 (мес. 10–12) — закрепить первые строки

**KPI:** топ-1…3 по всему обязательному ядру §3; топ-10 по ≥80% расширенного кластера; органика = главный источник заявок; индекс money-URL ≈ полный.

| # | Задача |
|---|--------|
| 1 | Актуальность FAQ и ориентира цен |
| 2 | Усилить победителей, отсечь мёртвые хвосты |
| 3 | Годовой отчёт → обновление этого ТЗ |
| 4 | 4-й город — только если три стабильно кормят |

## 6. Еженедельный ритуал

1. Health / weekly-run / дашборд.  
2. SEMANTICS + Wordstat.  
3. Одна ставка: усиление money-URL **или** 1 черновик content-writer **или** чеклист индекса/карточки владельцу.  
4. ≤1–2 новых URL; после деплоя — переобход.  
5. Короткий статус: индекс / позиции-прокси / заявки.

## 7. KPI

| Метрика | Где | Цель к концу года |
|---------|-----|-------------------|
| searchable_pages | Вебмастер | ≥ 45, money почти все |
| Визиты с поиска | Метрика | главный канал |
| Заявки form_submit (+ бот) | Метрика / LEAD | рост QoQ |
| Позиции ядра §3 | серп / Вебмастер раз в мес. | топ-1…3 |
| Карточка | Яндекс Бизнес | отзывы, фото, ответы |
| city_id заявок | форма / бот | не только Хабаровск |

Клики call/WA/TG ≠ заявки. Новые цели Метрики не создавать.

---

## 8. Definition of Done

Год выполнен, если одновременно:

1. «Ремонт телефонов» + каждый из трёх городов — **топ-3** (лучше топ-1).  
2. «Ремонт телефонов» в региональной выдаче края — **топ-5** (лучше топ-3).  
3. Хабаровск: замена экрана и батареи — **топ-3**.  
4. ≥2 услуги×город вне Хабаровска — **топ-10**.  
5. Доля визитов с поиска ≥ 50% в последнем месяце года.  
6. Заявки с органики ≥ 1/нед. в среднем за Q4.
