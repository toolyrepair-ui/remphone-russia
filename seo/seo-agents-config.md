# Конфиг 7 SEO-агентов — rem-phone.ru

Источник: мастер-план Фаза 3. **Пока каркас** — агенты запускаются вручную через Cursor / weekly-run, не как отдельные демоны.

Гео: Хабаровск · КнА · Владивосток. Канал №1 — Яндекс.

## Расписание

| Агент | Частота | Триггер |
|-------|---------|---------|
| 1 Семантика | 1× / 2 нед | Wordstat API (`seo/wordstat_fetch.py`) |
| 2 Техаудит | weekly | `node seo/weekly-run.mjs` / `health-check.mjs` |
| 3 Позиции | daily (когда есть API) | Вебмастер / GSC → `seo/positions-history.csv` |
| 4 Перелинковка | weekly | Волна B плана продвижения |
| 5 Конкуренты | 1× / мес | Pedant, Zoon, ServiceRating + локалы |
| 6 GEO/AEO | weekly | Вебмастер → Алиса AI → `seo/geo-aeo-queries.csv` |
| 7 Стратег | daily summary / weekly digests | Собирает 1–6 → Telegram (когда настроен канал) |

## Зоны ответственности (коротко)

1. **Семантика** — новые/сезонные фразы, сверка с `SEMANTICS.md`, не плодить thin URL.
2. **Техаудит** — sitemap, robots, JSON-LD, битые ссылки, дубли title/description.
3. **Позиции** — история день к дню; без API — ручной срез 5–10 money‑запросов.
4. **Перелинковка** — хаб ↔ услуга ↔ бренд ↔ город; один H1 = один город на city‑URL.
5. **Конкуренты** — структура контента (цены, FAQ, гарантия), не копипаст.
6. **GEO/AEO** — Share of Voice Алисы; gap: запрос → лидеры → страница Remphone.
7. **Стратег** — 1 приоритет на неделю + отчёт владельцу.

Пока **не подключены**. Когда будет бот/канал:

## Ограничения

- Не запускать Фазу 3 «агенты в проде» без рабочих целей Метрики и живого бота заявок.
- GEO/AEO: у малотрафикового сайта данных может не быть первые недели — норма.
- Вне скоупа: покупные ссылки, массовый автоген страниц, ИИ вне Яндекса.
