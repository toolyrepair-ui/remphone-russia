# Цели Метрики — актуальные идентификаторы

Код в `analytics.js` шлёт **JavaScript-события** с этими id. В интерфейсе Метрики цели должны совпадать **один в один**.

| Цель в интерфейсе | Идентификатор (как в коде) |
|-------------------|----------------------------|
| Клик телефон | `make-call` |
| WhatsApp | `whatsapp` |
| Telegram | `telegram` |
| Открытие формы | `request-form-open` |
| Отправка формы | `request-form-submit` |

Счётчик: `111453492` (`config.js` → `metrikaId`).

Проверка: клик tel / WA / TG / отправка формы → Отчёты → Конверсии (15–30 мин).

> Устаревшие имена из ранних заметок (`phone_click`, `whatsapp_click`, `form_submit`) **не** используются — не создавайте цели с ними.
