# План SEO‑продвижения rem-phone.ru

**Модель:** агрегатор заявок  
**Гео‑фокус:** Хабаровск · Комсомольск-на-Амуре · Владивосток  
**Дата:** август 2026  

Цель — не «максимум страниц», а заявки с локальных money‑запросов. Один слой услуги/бренда + перелинковка на города, пока контент тонкий.

---

## 1. Стратегия

### Делаем

- Яндекс + локальные запросы вида «услуга + город»
- Карточка Яндекс Бизнес как быстрый канал заявок
- Еженедельно 1–2 URL **или** 1 конверсионный фикс
- Перелинковка: хаб ↔ услуга ↔ бренд ↔ город

### Не делаем

- Не открываем 4‑й город без стабильных заявок с текущих трёх
- Не плодим отдельные URL бренд×город (thin content)
- Не индексируем off‑geo (Москва, СПб и др.)
- Не публикуем чужие телефоны мастерских (CTA = заявка / бот / наш телефон)

## 3. Дорожная карта

### Волна A — ближайшие 2 недели (индексация + заявки)

Приоритет волны A: **money‑URL в индексе** и каналы заявок. Блог сюда не входит.

| # | Задача | Кто | Зачем |
|---|--------|-----|-------|
| 1 | Переобход в Вебмастере: apps, body, brand-battery, city battery | Владелец | Ускорить индекс |
| 2 | Яндекс Бизнес: зона = 3 города, услуги apps/корпус, фото ≥3 | Владелец | Заявки быстрее органики |
| 3 | Wordstat: Хаб. край + Приморье — экран / батарея / apps / корпус | Владелец | Приоритет хвостов |
| 4 | Проверить цели Метрики: phone / WA / TG / form_submit | Владелец + агент | Измерять конверсию |
| — | Зафиксировать baseline KPI по КнА + Владивосток (см. §6) | Владелец | Точка отсчёта на 90 дней |

**После волны A** (когда ключевые money‑URL подтверждены в индексе / на переобходе):

| # | Задача | Кто | Зачем |
|---|--------|-----|-------|
| 5 | 1 инфо‑пост в `/blog/` → ссылка на услугу + 1 город | Агент | Поддержка money‑страниц, не замена |

Блог поддерживает service‑страницы и не должен конкурировать с ними за слот недели, пока money‑URL ещё не в индексе.

| Приоритет | URL / действие | Условие |
|-----------|----------------|---------|

| P2 | Доработать `/services/battery` и `screen`: один H1 = Хабаровск + блок «Где ещё» на city‑URL — **сделано 2026-08-16** | После Wordstat |
| P3 | Бренд × экран: нейтральный H1 + перелинковка на 3 города — **сделано 2026-08-16** | Как у батарей |
| P4 | Дожать анкоры apps/body с городских хабов | — |
| P5 | Blog (п.5 из хвоста волны A), если ещё не сделан | Money‑URL в индексе + city-URL в Метрике «Страницы входа» |

**Правило H1 (обязательно для P2 и любых правок `/services/*`):**

- Не писать в одном H1 «… в Хабаровске, КнА и Владивостоке» — это размывает локальный сигнал.
- Вариант A: H1 с одним городом (обычно Хабаровск, если страница исторически хабаровская) + блок «Где ещё» со ссылками на КнА и Владивосток.
- Вариант B: нейтральный H1 без города («Замена батареи») + блок городов со ссылками на `/cities/.../battery.html`, `/komsomolsk-na-amure/battery.html`, `/vladivostok/battery.html`.
- Локальный money‑сигнал держим на **городских** URL (один город = один H1).

| Идея | Не раньше чем |

- Структура: проблема → решение → CTA на услугу + один город
- Блог поддерживает service‑страницы, не заменяет их

## 6. KPI на 90 дней

| Метрика | Ориентир | Где смотреть |
|---------|----------|--------------|
| Индексация ключевых URL | Все money‑URL в индексе Яндекса | Вебмастер |
| Визиты с поиска (3 города) | Рост MoM без просадки CTR | Метрика |
| Заявки (форма + бот) | Стабильный недельный поток | Бот / цели Метрики |
| Доля КнА + Владивосток | Рост доли относительно baseline (§6.1) | `city_id` в заявках |
| Карточка Бизнес | Отзывы + сообщения | business.yandex.ru |

### 6.1. Baseline: доля КнА + Владивосток

Без зафиксированного старта через 90 дней нельзя честно оценить рост по двум новым городам.

| Поле | Значение |
|------|----------|
| Baseline‑неделя | **11–17 августа 2026** (неделя старта трёхгородного контура после деплоя apps/body и brand‑battery) |
| Метрика | Доля заявок с `city_id` ∈ {`komsomolsk`, `vladivostok`} от всех заявок с известным городом за неделю |
| Формула | `(заявки_КнА + заявки_Владивосток) / заявки_с_city_id × 100%` |
| Источник | Бот / Lead API (таблица заявок); дублировать срез в еженедельный отчёт `seo/reports/` |
| Как заполнить | В отчёте за неделю 11–17.08 записать: всего заявок с city_id, из них КнА, Владивосток, % — это **baseline %** |
| Оценка на день 90 | Сравнить средний % за последние 4 недели до ~10.11.2026 с baseline %; рост = улучшение, а не «стало не только Хабаровск» без цифр |

Если за baseline‑неделю заявок мало (меньше 10 с city_id) — продлить окно до **двух недель: 11–24 августа 2026** и явно отметить это в отчёте.
