Для кого: владелец + агент Cursor

## 1. Северная звезда

**12 месяцев:** органика Яндекса — основной канал заявок; по ядру запросов — **первые страницы**, по ключевым — **первые строки** (`seo/TZ_SEO_YEAR.md`).

**90 дней (до ~20.11.2026):** доказать, что канал работает цифрами, не «красивым сайтом».

| Метрика | Сейчас (~20.08) | Цель 90 дней |
|---------|----------------:|-------------:|
| Страниц в поиске Яндекса | 14 из ~56 | ≥ 40 |
| Визиты с поиска / мес. | ~7 | ≥ 80 |
| Заявки формы+бот / нед. | ~0–1 | ≥ 3 стабильно |
| Отзывы в Яндекс Бизнес | 0 | ≥ 10 |

Пилот спроса (go/no-go из `business-model.md`) **не отменяет** прямой сервис: считаем качество заявок и тянем ли сами объём.

## 3. Исходные факты (зачем такое ТЗ)

1. **Спрос большой, трафик крошечный.** Wordstat: «ремонт телефонов» 2600 / 4300 в краях; гео-хабы 400–1000+. Сайт: ~70 визитов/мес., из поиска единицы.
2. **Узкое место №1 — индекс (14/56),** не отсутствие посадочных. Money-URL по SEMANTICS в основном уже есть.
3. **Воронка живая:** 32 открытия формы → 2 заявки; сессия ~4 мин; отказы 34%. Продукт формы не «сломан» — нечего чинить в первую очередь.
4. **Карточка Бизнес отстаёт:** дубли, 0 отзывов; фото лежат в `yandex-biz-photos/`.
5. **Деньги в гео + поломках** (не включается, экран, батарея, зарядка). Бренд-фразы мелкие — не раздувать brand×city.
6. Локально не задеплоены (на момент брифа): прайс-таблицы / каталог моделей — отдельный шаг «выложить», не путать с SEO-волной индекса.

## 4. Потоки работ (workstreams)

Пять параллельных потоков. Приоритет слева направо в Q1: **A → B → C**, затем D/E.

### A. Индекс и выдача (SEO-фундамент)

**Цель:** money-URL в поиске Яндекса.

| # | Задача | Кто |
|---|--------|-----|
| A1 | Список money-URL на переобход (гео, screen/battery/water×3, brands screen/battery, apps/body, `/`) | Агент |
| A2 | Переобход в Вебмастере + проверка sitemap на проде | Владелец |
| A3 | Мониторинг `searchable_pages_count` (дашборд) раз в неделю | Агент + крон |
| A4 | Усиление title/H1/description/FAQ/перелинковки под Wordstat 20.08 («в хабаровске», «сервисный центр», not-on, charge) | Агент (`direct-service-voice`, `yandex-local`) |
| A5 | Wordstat refresh раз в 1–2 мес.; полный Приморье после квоты | Агент |
| A6 | Ежемесячный срез позиций по ядру (серп / Вебмастер) | Агент + владелец |

Детали кварталов и DoD года — `seo/TZ_SEO_YEAR.md` (не дублировать здесь целиком).

### B. Яндекс Бизнес (быстрые заявки)

**Цель:** карточка кормит заявки параллельно органике.

| # | Задача | Кто |
|---|--------|-----|
| B1 | Склеить дубли карточек | Владелец |
| B2 | Загрузить фото из `yandex-biz-photos/`, лого | Владелец |
| B3 | Описание и услуги из `seo/YANDEX_BUSINESS.md` (прямой оффер) | Владелец |
| B4 | Зона: 3 города; график как в `marketing.md` (08–20) | Владелец |
| B5 | Процесс: после ремонта → просьба отзыва (шаблон текста) | Агент пишет шаблон → владелец шлёт |
| B6 | Отвечать на отзывы в течение 48 ч | Владелец |

### C. Конверсия сайта (уже есть трафик / тесты)

**Цель:** не потерять редкий визит; измеримость.

| # | Задача | Кто |
|---|--------|-----|
| C1 | Задеплоить на REG.RU: прайс-ориентиры + каталог моделей (если ещё локально) | Агент по команде «деплой» |
| C2 | Проверка целей Метрики (form_open / submit / call / WA / TG) на проде | Агент Playwright + владелец |
| C3 | `LEAD_STATS_URL` для заявок бота на дашборд — когда готово на Render | Владелец секреты + агент проводка |
| C4 | Не трогать UX формы без сигнала; мелкие копирайты CTA — ок | Агент |
| C5 | 3D-калькулятор — поддержка, не главный SEO-рычаг | по отдельной задаче |

### D. Контент (после сдвига индекса)

**Цель:** не плодить страницы «в пустоту».

| # | Задача | Условие | Кто |
|---|--------|---------|-----|
| D1 | 1 blog/мес. → услуга + один город | money-URL начали индексироваться | `content-writer` → PR |
| D2 | Дожим `/services/not-on.html`, `charge.html` + city-связи | всегда приоритетнее новых брендов | Агент |
| D3 | Новые URL только если частота > 0 и нет посадочной (напр. акцент «сервисный центр Хабаровск» на существующий хаб, не новая оболочка) | Wordstat | content-writer / усиление |
| D4 | Brand×КнА/Владивосток отдельные URL | не раньше стабильных визитов на city screen/battery | позже |
| D5 | Планшеты / часы / разблокировка | нет частот — не SEO-волна | стоп |

## 5. Фазы по времени

### Фаза 0 — сейчас (1–2 недели): «включиться в поиск»

1. A1–A2 переобход money-URL.  
2. B1–B4 карточка.  
3. C1 деплой прайса/моделей (если ещё не на проде).  
4. Не писать пачку новых лендингов.

**DoD фазы 0:** searchable растёт week-over-week; карточка без дублей с фото; прод = то, что в репо по прайсу.

### Фаза 1 — дни 15–45: «первые страницы по ядру»

1. A4 дожим хабов и P0 услуг под Wordstat.  
2. B5–B6 отзывы.  
3. D2 not-on / charge.  
4. D1 первая blog-статья после заметного роста индекса.

**DoD:** топ-20…10 по «ремонт + город»; ≥1 заявка/нед. с поиска или карточки.

### Фаза 2 — дни 45–90: «заявки как система»

1. Позиции → топ-10 по гео-ядру.  
2. КнА/Владивосток появляются в `city_id` заявок.  
3. Отзывы ≥10.  
4. Решение по пилоту: тянем сами / усиливаем привлечение / стоп масштаба.

### Фаза 3 — мес. 4–12: по `seo/TZ_SEO_YEAR.md`

Q2 первая страница → Q3 первые строки → Q4 закрепление.  
4-й город — только после стабильных заявок с трёх.

## 8. Definition of Done «развитие пошло правильно» (90 дней)

Одновременно:

1. searchable ≥ 40.  
2. Визиты с поиска ≥ 80/мес.  
3. ≥ 3 заявки/нед. в среднем за последние 2 недели (форма и/или бот).  
4. Карточка: фото live, дубли убраны, ≥10 отзывов.  
5. Хотя бы одна заявка с `city_id` КнА или Владивосток.  
6. Нет thin model×city и нет второго счётчика аналитики.
