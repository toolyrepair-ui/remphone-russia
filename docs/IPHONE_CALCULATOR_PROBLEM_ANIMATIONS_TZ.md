# Анимации неисправностей универсального 3D-калькулятора

Актуальная матрица для `3d-viewer-iphone15.html`. Текущая 3D-модель — демонстрационная; пользовательский интерфейс не привязан к бренду.

## Общие правила

1. Камера показывает нужную деталь, но не обрезает корпус.
2. Полные диагностические кольца и овалы не создаются.
3. `zoneLayout()` хранит только невидимые локальные якоря.
4. Дефект объясняется физическим признаком: экранной историей, движением детали, поверхностной картой, влагой или мягким локальным светом.
5. Все локальные FX учитывают `glassOut`, `backOut`, depth test и окклюзию.
6. Reduced motion показывает статичный итоговый кадр.

## Матрица категорий

### Дисплей

- `cracks-works`, `glass-only`, `shattered`: трещины/сколы на OLED.
- `black-sound`: чёрный OLED и короткий физический shake.
- `stripes`, `partial`: дефекты матрицы.
- `no-touch`, `ghost`: экранная история сенсора.

### Не включается

- `no-response`, `after-drain`: мёртвый OLED и короткий ход power.
- `black-rings`: чёрный OLED и короткий shake без графических колец.
- `logo-loop`, `reboot`: цикл логотипа/перезагрузки.
- `after-drop`: мёртвый OLED и одна тонкая трещина.

### Вода

- `recent`: небольшие капли на OLED и рамке.
- `unstable`: капли и нестабильное изображение.
- `dead-water`: чёрный OLED и статичная влага.
- `fog-camera`: fog-disk только на линзе.
- `no-sound-water`: влага у нижней сетки, без звуковых окружностей.
- `no-charge-water`: капли у USB-C, без искр.

### Батарея и нагрев

- `drains`: контролируемое падение процента.
- `percent-off`: выключение при остаточном заряде.
- `swollen`: экран смещается наружу, вдоль грани видна щель.
- `heat-charge`, `heat-idle`, `heat-after`: тёплый локальный свет и спокойная экранная история.

### Не заряжается

- `no-charge`: USB-C в крупном ракурсе, короткая попытка контакта.
- `angle`: телефон/контакт слегка наклоняется.
- `drops`: контакт кратко появляется и пропадает.
- `slow`: медленное изменение badge.

### Кнопки

- `power`: короткий proxy-ход правой кнопки.
- `volume`: последовательный ход кнопок громкости.
- `mute`: короткое движение переключателя / Action Button.

### Камера и Face ID

- `rear`, `front`: неисправный preview без круговой подсветки.
- `focus`: короткая пачка jitter с длинной паузой.
- `lens-glass`: трещина только на одной линзе.
- `face-id`: экранная история Face ID и краткие точки, без колец.

### Звук

- `earpiece`: две тонкие незамкнутые дуги у разговорного динамика.
- `speaker`: одна слабая серия незамкнутых дуг у нижней сетки.

### Корпус и крышка

- `back-glass`: crack-plane + отдельный angle-dependent highlight.
- `bent`: согласованная vertex-деформация всех mesh по длинной оси.
- `scratched`: группы тонких рисок, заметных главным образом под скользящим углом.
- `camera-glass-body`: crack-plane размером с одну линзу.
- `screen-gap`: наружное смещение OLED, тёмная щель и слабый внутренний блик.

### Другое

- `network`, `lag`, `after-update`, `pc`, `data`, `custom`: нейтральные экранные истории или статичный 3/4, без выдуманной физической поломки.

## Сброс состояний

При каждой смене symptom:

- скрываются старые surface FX;
- прекращаются spark, fog, shake и screen animation прошлого сценария;
- кнопочный proxy возвращается в базовую позицию;
- экран возвращается к исходной позиции, если новый сценарий не требует щели;
- vertex bend включается только для `body:bent` и полностью сбрасывается для остальных сценариев.
