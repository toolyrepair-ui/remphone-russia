# Бизнес-модель и KPI

## Развилка

Две возможные модели:

1. **Прямой сервис** — сами принимаем, чиним, отвечаем за гарантию.
2. **Агрегатор лидов** — заявка → партнёрская мастерская, мы не называем чужие адреса.

**Сейчас:** прямой сервис. Клиенту говорим: **«Отправьте заявку — мы отремонтируем.»**  
Утверждено владельцем **2026-08-16**. Это новее полного отчёта Perplexity (10.08), где ещё стояла развилка.

90-дневный пилот из go/no-go **не отменяет** прямой сервис: пилот проверяет **спрос и качество заявок**, а не «сразу продавать лиды». На HTML ещё местами текст про партнёров — это долг контента, не смена модели.

### Когда снова смотреть агрегатор

Из отчёта Perplexity 10.08 (после пилота, по цифрам):

| Исход пилота | Решение |
|--------------|---------|
| Заявки есть, сами тянем объём | Остаёмся прямым сервисом, потом города |
| Заявок много, сами не тянем | Тогда агрегатор: 5–8 партнёров на город, цена лида, учёт |
| Заявок почти нет, привлечение дорогое | Стоп: не масштабировать, пересмотреть оффер/каналы |

Ориентиры **только если** пойдём в агрегатор (из записки, не текущий прайс клиенту): цена лида 300–450 ₽, конверсия заявки в оплату 25–30%. Пока это гипотеза, не факт.

Не строить CRM / партнёрский кабинет, пока заявок меньше ~10–15 в неделю — хватает Telegram.

Юрстатус: **самозанятый (НПД)**, не ИП. Карточка Яндекс Бизнес «Онлайн», адреса мастерских не публикуем.

Из сессии Perplexity «НАЛОГИ»: для соло без сотрудников и дохода до **2,4 млн ₽/год** — НПД (4% с физлиц, 6% с юрлиц/ИП, чек в «Мой налог», без декларации и обязательных взносов). Регион в приложении — Хабаровский край. Когда понадобятся сотрудники, лимит или регулярный B2B — переход на ИП УСН. Perplexity отвечал ещё и про digital-услуги — для REMPHONE берём только статус/ставки, не «продажи сайтов».

## Как зарабатываем сейчас

Заявка (сайт / бот / звонок / WhatsApp) → диагностика → ремонт → оплата клиентом.  
Цифры маржи, среднего чека и доли выезда в репозитории нет.

## Пороги следующих решений

Из семантики и мастер-плана, не выдумывать новые:

| Решение | Пока не делать, пока… |
|---------|------------------------|
| 4-й город | нет стабильных заявок с текущих трёх |
| Thin URL модель × город | частоты бренд-фраз низкие |
| Отдельные brand×КнА/Владивосток URL | нет визитов на city-страницы |
| Blog-пост | money-URL не в индексе / нет входа с city |
| Покупка рекламы | не просили; сначала органика + карточка |
| Фаза 3 «агенты в проде» | нет рабочих целей Метрики *и* живой ленты заявок — цели уже есть, ленту заявок проверить |
| Дашборд | сделан минимальный: `dashboard/` (визиты, заявки, конверсия, sitemap). Живые цифры — после токена Метрики |
