# Бизнес-модель и KPI

## Развилка

Две возможные модели:

1. **Прямой сервис** — сами принимаем, чиним, отвечаем за гарантию.
2. **Агрегатор лидов** — заявка → партнёрская мастерская, мы не называем чужие адреса.

**Сейчас:** прямой сервис. Клиенту говорим: **«Отправьте заявку — мы отремонтируем.»**

Выбор «остаться прямым или стать агрегатором» отложен на 90-дневный пилот. На HTML ещё местами текст про партнёров — это долг контента, не смена модели.

Цифры маржи, среднего чека и доли выезда в репозитории нет.

## Пороги следующих решений

Из семантики и мастер-плана, не выдумывать новые:

| Решение | Пока не делать, пока… |
|---------|------------------------|
| 4-й город | нет стабильных заявок с текущих трёх |
| Thin URL модель × город | частоты бренд-фраз низкие |
| Отдельные brand×КнА/Владивосток URL | нет визитов на city-страницы |
| Blog-пост | money-URL не в индексе / нет входа с city |
| Покупка рекламы | не просили; сначала органика + карточка |
| Фаза 3 «агенты в проде» | нет рабочих целей Метрики *и* живой ленты заявок — цели уже есть, ленту заявок проверить |
| Дашборд | сделан минимальный: `dashboard/` (визиты, заявки, конверсия, sitemap). Живые цифры — после токена Метрики |

Пилот 90 дней: смотреть визиты, заявки, конверсию. Пока визитов 8/мес — любые проценты конверсии бессмысленны; сначала объём.
