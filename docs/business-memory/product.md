## Виды ремонта

**Ядро (есть услуга × город):**

- экран / дисплей
- батарея / аккумулятор
- после воды
- не заряжается / разъём
- не включается

**Есть страницы услуг, гео слабее:** камера, установка приложений (APK / вне магазинов), задняя крышка / корпус, динамик-микрофон / чистка.

**Карточки на `/services/` без отдельных URL:** замена стекла, планшеты, смарт-часы, восстановление данных, разблокировка.

## Как это звучит для клиента

Утверждено владельцем 2026-08-16:

**«Отправьте заявку — мы отремонтируем.»**

Не «подберём партнёрский сервис». Чиним сами. Заявка → диагностика → ремонт. 30–60 минут на типовые работы, диагностика бесплатно, гарантия 90 дней на все работы, выезд мастера.

На HTML-страницах ещё местами старая формулировка про партнёров — менять тексты сайта только отдельной задачей, не из этой папки.
