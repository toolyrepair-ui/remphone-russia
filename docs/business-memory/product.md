## Как это звучит для клиента

Утверждено владельцем 2026-08-16:

**«Отправьте заявку — мы отремонтируем.»**

Не «подберём партнёрский сервис». Чиним сами. Заявка → диагностика → ремонт. 30–60 минут на типовые работы, диагностика бесплатно, гарантия 90 дней на все работы, выезд мастера.

Публичные HTML (главная, города, услуги, бренды) приведены к этой фразе 19.08.2026. Блок «сервисы рядом» после заявки скрыт.

## Что ещё есть в памяти Perplexity (не путать с текущей моделью)

Computer Memory на 19.08 всё ещё хранит более раннюю картину: «лиды передаём мастерским, как такси; своих точек нет; сотрудничает с двумя мастерскими». Это **перебито** решением 16.08: чиним сами, чужие адреса не публикуем.

Дополнительное направление из той же памяти (не основной сайт): поиск и закупка в Китае (проверка поставщика, выкуп, логистика, таможня, видеоотчёт) — **не делать страницы без отдельной задачи**.

Блок «сервисы рядом с вами» с чужими точками на карте — не делать: это тонкий URL/адреса, которые запрещены.
